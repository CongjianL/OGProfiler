# 递归停止语义与818蛋白节点专项审计

日期：2026-10-02。来源：H4 job `1410775`。
范围：源代码、已冻结H4层级、818节点诱导图、小型本地诊断。
**生产代码/config/阈值/OG/scorer未改变；未提交新Slurm作业。**

## 结论

1. **默认stop_size=1的结构递归并非相对V1新引入的“拆到单蛋白”政策。**
   V1同样对多物种2蛋白节点直接分成两singleton，对更大的多物种小节点继续二分。
   H4中71.2%的singleton是结构叶比例，不是最终OG的singleton比例。
2. **真正的V1差异是拓扑目标和搜索/准入，而不只是停止尺寸。**
   V1对3–9,999蛋白多物种节点要求二分；V2保留稳定k-way。
   本次8448个小于10000蛋白的split为k-way，属于ADR明确政策差异，不是条件写反。
3. **818节点失败至少包含两种独立机制。**
   稳定的810+8二分因最大子群比例0.99022被拒绝；更均衡划分在2次迭代下的ARI不足0.9。
4. **优化预算是可验证的原因之一，无需降低可靠性阈值。**
   对固定818图，seed、method、weights、ARI阈值、最大子群比例与搜索配置全保持不变，
   `n_iterations=10`的有限诊断使公共search接口接受一个候选，ARI=0.913175。
   这不是全运行验收，也不证明10次已彻底收敛，更不证明该分裂生物学正确。
5. 当前生产UNRESOLVED及下游阻断符合ADR；现在没有依据把818强行标为SIZE_STOP，
   或仅因它没有RefOG成员就忽略它。下一步设计讨论应优先明确优化充分性预算，
   并独立决定是否要求V1二分拓扑；停止尺寸调整须显式修订ADR。

## 1. 三种语义应继续分开

| 层 | 问题 | 当前事实 |
| --- | --- | --- |
| partition准入 | 候选能否成为子节点 | 非空singleton合法；保留最大比例、tiny比例、ARI门槛 |
| 递归停止 | 当前结构节点是否继续构造后代 | 单蛋白、单物种、明确size policy停止 |
| OG选择 | 哪些结构节点成员成为最终OG | 独立V1事件/提取规则，存在内部节点选择与后代失活 |

`recursion_stop_size`是粒度政策，不是同一orthogroup的证据。
SINGLETON/ONE_SPECIES/SIZE_STOP表示流程的政策完成；UNRESOLVED表示本轮搜索未解决。
低gamma得到一群，也只是某个gamma下的未分裂结果，不自动升级成生物学停止条件。
当前设计没有独立的“已有生物证据判定无需分裂”状态。

当前实现顺序：SINGLETON → SIZE_STOP → ONE_SPECIES → DEPTH_LIMIT → NO_EDGE_SUPPORT。
默认stop_size=1时，2蛋白及以上的多物种、有边节点继续搜索。
这与ADR 0002一致，不应把其科学粒度后果描述成实现bug。

## 2. 与V1源码的逐项对照

`legacy/OGProfiler_v1.py` 的 `HHN.RunCommunityDetection`：

- 多物种且n>=10000：目标20–50子群；实际返回>=2群则继续。
- 多物种且2<n<10000：目标恰好2群；实际恰好2群才继续，否则记结束。
- 多物种且n=2：**不调用Leiden，直接生成两singleton子节点**。
- 其余：停止（包括单物种）。

`GetConnectedOfCCsV2`不断调用上述方法直到没有待处理子群。
因此V1没有“2/3蛋白多物种组自然成为终止OG”的默认语义；
也没有“一物种一个蛋白就停止”的条件。把stop_size改为2或3会改变V1风格的结构语义。

V1的SpecificBoard/BipartiteGraphs明确使用n_iterations=10；不测三seed平均ARI，
不检查最大子群占比.95。搜索的目标是群数，gamma区间和失效退出也与V2不同。
V1失败时记终止，V2现在记UNRESOLVED；两者科学完成状态明确不等价。
本审计没有重跑原V1的潜在1000步搜索，不把源码允许的候选误写成V1实际选中结果。

V2则保存任意稳定k-way；H4根444子群，其4874蛋白/11物种子节点64983又分成38群。
818节点路径为 `0 → 64983 → 67915`。这些拓扑已不同于V1的20–50/二分策略。
H4共有19,727个binary split与8,449个k-way split；其中8,448个k-way父节点n<10000。
即使停止规则相近，输入OG引擎的事件拓扑也不同：V1事件中>2个较小邻居会走III-3，
而非按二分的物种重叠分支判事件。这是一条值得单独验收的准确度影响路径。

## 5. 原生产全拒绝的具体机制

`.02`的三seed均给出810+8，三对ARI均1.0；
但最大子群比例810/818=.990220>.95，所以准入拒绝。
810大组跨9物种，8小组跨6物种。V1源码的二群准入不包含.95门槛，
因此同一个两群候选按V1结构判定会获准；这不等于原V1搜索实际会选择该gamma。

其他满足最大比例的候选在2次迭代设置下均ARI<.9。
例如gamma=1.28：三seed分别45/47/49群；
三对ARI=.878884/.909438/.903639，mean=.8973204470525067，代表seed为第三个。
指标计算正确；不是把NMI当ARI，也不是membership对齐或种群数错误。

`.01`一群稳定、`.02`两群稳定但比例过大、更细划分不稳定：
这是**目标/准入冲突 + 优化预算敏感性**，不是singleton准入再次出错。

   不将818标作SIZE_STOP，也不从正式成员覆盖中跳过它。

   两者均改变hierarchy科学执行策略；需新identity/版本与来源明确的H4/H5验证。
3. 若采用回退，gamma复用key须含优化迭代设置；所有实际评价都计入共享总预算。
   原818已花19候选，另叠一轮11候选=30会超过24；不可把每阶段各24冒充每节点总24。
   Leiden调用数与每调用迭代数是两种预算，均应显式记录；不使用无界n_iterations=-1。
4. V1 binary目标与V2 k-way须单独做设计选择与对照，不混入迭代充分性修复。
   先证明818及完整后代resolved，再固定新hierarchy执行OG parity与官方评分。
5. 单独评估2蛋白结构特判的可观测语义/省调用潜力；不通过提高停止尺寸偷偷改变拓扑。

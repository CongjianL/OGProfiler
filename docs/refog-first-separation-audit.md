# 低召回RefOG：首次物理分散与OG未重新合并的定位

Date：2026-10-02；冻结来源job `1410777` / commit `cb0c0ba`。

## 方法与边界

追踪全部70个RefOG，而非只看最差案例。按官方规则分别去除该RefOG的低可信成员，
保留1,895个可信蛋白、39,242个真值无序蛋白对。原始ID → protein_id → SSN
component → hierarchy terminal及祖先路径 → V1 event/selection trace → 最终OG。

取回相关67组件的诊断，不重新运行Leiden、SSN、OG或scorer。hierarchy和OG诊断表
哈希均核对其提交manifest。官方默认q_even对各RefOG的蛋白对计数使用权重
`1/(n_confident-1)`；以下百分点按相同分母947.5计算。
由最终分组重建recall=.2559107700937722，与官方实际函数结果精确一致。

**首次物理分散不等于不可恢复损失。** 同一OG可跨结构叶；只对最终落入不同OG的
蛋白对定位其SSN分量或hierarchy最低共同祖先（LCA）。如果同一结构叶被OG阶段再拆散，
审计会报错；本次没有发现此现象。另检查LCA及全部共同祖先是否满足现有选择资格：
event I且species level>=2，或裸None对应level1残余选择。

## 1. 官方召回的精确分解

| 去向 | 原始蛋白对 | 官方权重对应百分点 |
| --- | ---: | ---: |
| SSN阶段已跨连通分量，最终未保留 | 6,046 | **12.808652** |
| 同SSN组件内，hierarchy分开后最终未重新合并 | 27,474 | **61.600271** |
| 最终保留 | 5,722 | **25.591077** |
| 合计 | 39,242 | 100 |

35/70个RefOG已跨多个SSN组件；另35个完全在单一组件内。
SSN跨分量损失占最终加权丢失关系的17.21%，同组件内损失占**82.79%**。
在保持组件独立的前提下，当前SSN能支持的成对召回理论上界是87.191348%；
这只是全部组件内关系都正确保留的乐观上界，不是准确率预测，也不证明SSN每条边正确。

实际hierarchy结构叶只保留267对（1.075864个百分点）；OG选择又从不同结构叶中
重新合并5,455对（24.515213个百分点），最终达到25.591077%。
因此不能把结构singleton比例直接当作最终OG的碎片化比例，也不能直接用terminal代替OG。

## 2. 事件/选择阶段发生了什么

对27,474个同组件内丢失关系，**全部没有符合现有规则的共同可选择祖先**。
没有发现覆盖该蛋白对的共同合格候选因SKIPPED_CONSUMED或排序而漏选的案例；
也没有同一结构叶在OG阶段首次被拆开的案例。结合固定hierarchy真实V1 parity已通过，
当前证据指向**hierarchy划分与V1事件资格的衔接**，而不是实际OG选择实现与V1规则不一致。

这些蛋白对首次分散节点的事件：

| LCA事件 | 原始丢失对 | 官方权重对应召回损失百分点 |
| --- | ---: | ---: |
| III-3（>2个严格较小子群） | 20,098 | **40.716326** |
| III-1（binary，但一个子群覆盖父物种集合） | 6,481 | **18.580321** |
| III-2 | 772 | 2.047696 |
| II | 123 | .255928 |

III-3占同组件内加权损失约66.10%，是最大机制；但binary也有III-1/III-2/II，
不能由此推导“统一binary就必然恢复全部准确度”。这些是对当前冻结产物的路径定位，
不是更改拓扑后的反事实全pipeline实验。

## 3. 最清晰的案例：RefOG001

- 15个可信蛋白全部在SSN **component2694**，与其根的15个成员完全相同。
- 根node0：12物种、gamma=.7610925536017414，分成4个子群，event **III-3**。
  从根开始，39个最终丢失关系首次被分开。
- node2：12蛋白/11物种，binary但event **III-1**，首次分开11对。
- node3：**11蛋白/11物种，每物种一个蛋白**，gamma=1.522185107203483，
  分为11个singleton，选中ARI=1，event **III-3**，首次分开55对。
- 三个共同祖先都不满足I/None选择资格；最终15个预测组，105对全部丢失。

尤其node3说明：稳定性1也不证明正交群应被拆散。当前多路树让11个完全不重叠的
物种子群标III-3，而不是I。直接调用未修改的公开V1事件函数验证：
11个子群的实际事件III-3；将相同11个species bitmap仅在事件代数中假设为两个
不重叠子群，事件成为I。

这只是**事件代数characterization**：没有生成新的Leiden划分，没有改生产事件规则，
也没有声称该假设binary在实际搜索中一定通过既有门槛。
V1小于10,000蛋白多物种节点目标为exactly2，而V2接受稳定k-way；
本案例给出了该拓扑政策差异如何破坏V1选择资格的直接链条。

## 5. 下一步设计焦点，而非自动修改

优先审计/显式设计 **V1小节点binary分裂目标 vs 当前k-way准入**，先以component2694
及其他低召回小组件作固定SSN对照；分别记录候选是否存在、是否通过现有阈值、
事件资格是否改变，以及真实OG结果。不得只将III-3文本改成I来掩盖拓扑差异。
同时保留binary III-1反例，避免把所有低召回归因于k-way。

停止尺寸1、稳定性阈值.9、每节点候选预算与OG/scorer保持原样。
若改变分裂目标或拓扑政策，须显式修订既有k-way ADR，不能当作条件写错的修补。
SSN跨分量损失是独立问题，随后沿对应蛋白的hits→NBS→connect→保留边审计；
本次不把87.19%的上界误解为OF或历史V1的SSN已证实一致。

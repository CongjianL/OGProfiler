# penalty=0.1 新增误合并诊断协议

固定 job1411414/candidate-02（0.1）、job1411104/current-soft42、原 OF 参考。
不重跑 Leiden、不扩大参数列表、不在诊断结果前修改评分。

1. assigned-only 计数，利用新组×旧组×参考组列联表精确算出 new FP、retained FP、
   new TP；再由旧组总量得到 removed FP、lost TP。净差不冒充新增错误数量。
2. 对所有 new FP>0 的新组检查所选节点的直接子群边界；不截断 top-k。
   同时记录全部 fp=0 且 new TP>0 的组作描述性对照，并明确它们未作尺寸匹配。
3. 仅正权跨直接子群边参与边界统计：端点覆盖率、最小子群覆盖率、连接的子群对
   比例、最大边权占比、前10%边的权重占比、端点权重份额HHI及最大份额。
   单条边两端各计一次，端点份额分母为2×跨边总权重。无跨边时集中度为null。
4. 参考不一致内部边权比例仅作标签驱动诊断，不作为未来评分特征；分母包括
   完整成员内的边权，未分配蛋白不被当成参考负例，解释时保留这一口径。
5. checksum绑定原批量报告、evaluation成员哈希与全部消费输入，结束时重核；
   蛋白唯一覆盖、分组完整子树身份和全量TP/FP总数独立核对。
6. 分组尺寸和多叉程度会影响集中度，因此描述性差异不是桥接的因果证明。
   诊断返回后再决定是否引入覆盖约束/局部尺度，不事先保证任何规则有效。

Slurm脚本 `slurm/embleya_merge_diagnosis.sh`，单作业2CPU/8GB/2h，
先3项fixture smoke再读取冻结产物。输出每组诊断与精确pair转移总计，生产默认不变。

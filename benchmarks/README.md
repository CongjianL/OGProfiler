# OGProfiler regression and performance benchmarks

`datasets/` contains deterministic synthetic fixtures generated by
`generate_phase0_datasets.py`. Each dataset has four proteomes, a ground-truth
membership table, a checksum manifest describing the behavior it targets, and
a deterministic `reference_ssn.gml`. The reference SSN isolates hierarchy
testing from homology-search variability; it is not presented as search output.

Regenerate and verify the fixtures with:

```bash
python benchmarks/generate_phase0_datasets.py --check
```

V1 baseline outputs belong under `baseline_v1/<dataset>/`. Raw external-tool
outputs may be stored outside Git when large; their manifest and summarized
metrics remain version controlled.

## Dataset roles

- **A**: ten one-to-one families plus species-specific singletons.
- **B**: recent duplications for RBH/non-RBH/LRB regression.
- **C**: a 60-protein expansion with three planted subclades.
- **D**: domain-only proteins and fusion bridges for coverage sensitivity.
- **E**: one 240-protein component with six planted subfamilies.

## Phase 2 exit benchmark

The Phase 2 exit benchmark uses the C/E `reference_ssn.gml` fixtures directly,
runs three frozen-V1/V2 hierarchy repeats per dataset through
`slurm/phase2_reference_benchmark.sh`, and aggregates deterministic normalized
topology, runtime, RSS, Leiden-call, and subgraph-construction metrics with
`aggregate_phase2_reference.py`.

Phase 3 real-backend smoke artifacts are stored under `phase3_search/`. They
preserve the standard directional hit table and checksummed search manifest
from a small remote DIAMOND integration run.

Phase 4 Dataset D coverage-sensitivity evidence is stored under
`phase4_edges/20260826_dataset_d/`. It compares 0% and 50% directional coverage
cutoffs using the same DIAMOND hit table and records candidate and retained-edge
counts in checksummed manifests.

Phase 5 component-index and partition evidence is stored under
`phase5_components/`. The Dataset E run exercises largest-component ordering,
partition-local loading, and manifest/checksum verification.

Phase 6 production hierarchy evidence is stored under `phase6_reference/`.
The Slurm C/E run records robust multi-seed hierarchy metrics, component-local
artifacts, verified resume, runtime, RSS, and immutable submission provenance.

Phase 7 scheduler evidence is stored under `phase7_scheduler/`. The Slurm C/E
run records largest-first dispatch, component task state, parallel execution,
and a second invocation that checksum-verifies and skips every completed task.

Phase 8 network-event evidence is stored under `phase8_network/`. The C/E
integration regression annotates the frozen Phase 7 hierarchy artifacts,
archives fixed-schema event tables and checksum manifests, and verifies that a
second invocation reuses every component.

Phase 9 final-export evidence is stored under `phase9_exports/`. The C/E
integration regression assembles terminal families, assigns canonical stable
OG IDs, writes the four MVP TSV tables, and verifies output checksums and
immediate resume.

Phase 10 hierarchy-driven orthology evidence is stored under
`phase10_orthology/`. The remote streaming regression emits 60,000 unique
cross-species candidates from a four-child disjoint polytomy in 15 bounded
chunks, validates Zstandard output, and verifies immediate checksum reuse.

Phase 11 phylogenetic-refinement evidence is stored under
`phase11_phylogeny/`. A real remote MAFFT/FastTree run refines one 40-gene
reference-E family with species-tree-aware rooting, LCA reconciliation,
independent network/phylogenetic events, and verified family-level resume.

Phase 12 scientific-selection preflight is stored under
`phase12_scientific/preflight/`. It contains the deterministic 16-row OFAT
matrix, reference C/E scientific metrics, frozen-V1/V2 comparisons, and the
closed external-method registry. Formal matrix rows are executed with
`slurm/phase12_scientific_matrix.sh` and aggregated by
`aggregate_phase12_matrix.py`.

The completed formal run is archived under
`phase12_scientific/20260826T075642Z_b2f54a90/`. All 16 Slurm tasks completed,
all Dataset A family metrics were perfect and invariant across the matrix, and
the evidence-backed decision is to retain the baseline defaults rather than
select a parameter from tiny-run timing noise.

* Entry point: `ogprofiler = "ogprofiler.cli:main"` in `pyproject.toml`. `src/ogprofiler/cli.py:build_parser()` defines `run`, `prepare`, `search`, `edges`, `components`, `hierarchy`, `hierarchy-all`, `annotate-network`, `export`, `orthologs`, and `annotate`.

No documented CLI for injecting/reusing a precomputed SSN: the supported precomputed-network path is only `prototype-hierarchy --ssn GML`.
* Terminal outputs: `run/results/families.tsv`, `members.tsv`, `hierarchy.tsv`, `events.tsv` (README Outputs; generated by `src/ogprofiler/output/results.py:assemble_export_tables`).

* Core clustering: production hierarchy stage is callable after prepared/partitioned edges (`hierarchy --run --component-id` or `hierarchy-all --run`). `prototype-hierarchy` is GML-only legacy import.
